# Telegram-style Login Page

Учебная страница входа, стилизованная под Telegram Web. Создана в образовательных целях для практики HTML и CSS.

> ⚠️ **Важно:** это **не** настоящий Telegram и **не** его копия. Страница не отправляет данные, не подключается к серверам и не выполняет вход. Код написан с нуля и использует только похожую цветовую схему и компоновку.

---

## 📋 Описание

Одностраничный сайт с формой входа:
- Логотип Telegram в виде SVG (бумажный самолётик в синем круге с градиентом)
- Поле для ввода номера телефона
- Кнопка «Далее» с заглушкой вместо реального входа
- Адаптивная вёрстка (корректно отображается на телефонах и компьютерах)
